服务概览 & 音频格式说明

服务地址: http://192.168.1.197:8090（调试期间为本机 IP）

CORS: 已开启 allow_origins: ["*"]，H5 跨域无需额外配置。

音频格式兼容性（前端 AAC/MP3/WAV）

接口 输入格式 输出格式 前端兼容说明
POST /tts（edge-tts 主引擎） — audio/mpeg (MP3) ✅ 前端可直接用 <audio> 播放
POST /tts（sherpa-onnx 兜底） — audio/wav (WAV) ✅ 前端可直接用 <audio> 播放
POST /asr WAV / MP3 JSON ⚠️ 不支持 AAC，需转 WAV 或 MP3 上传
WS /asr/stream PCM 16kHz mono JSON 非文件格式，需前端 Recorder 采集原始 PCM
POST /kws/check WAV JSON ⚠️ 不支持 AAC/MP3，仅 WAV
WS /kws/stream PCM 16kHz mono JSON 非文件格式，需前端 Recorder 采集原始 PCM
重要提示：
  • TTS 返回：edge-tts 返回 MP3，sherpa-onnx 返回 WAV。两种都是 audio 流，前端用同一个 Blob 处理即可，通过响应头 X-TTS-Engine 可区分引擎。
  • ASR 上传：支持 WAV 和 MP3 文件上传。不支持 AAC，如果前端录制的是 AAC，需在前端转成 WAV 再上传，或改用 WebSocket 流式传输 PCM。
  • KWS 上传：仅支持 WAV 文件上传。
  • WebSocket 流：ASR 和 KWS 的 stream 接口需要前端发送 16-bit PCM, 16kHz, mono 原始音频帧，不是文件格式。H5 端建议用 RecorderManager 或 getUserMedia + AudioWorklet 采集。

TTS 语音合成 （Text to Speech）

文本转语音。主引擎 edge-tts（微软 Azure 神经网络 TTS，在线免费），兜底引擎 sherpa-onnx Kokoro（离线本地）。

⭐ 推荐使用 POST /tts/synthesize（JSON Body）。
长文本（几百字以上）务必用 Body 方式，没有 URL 长度限制；POST /tts（Query String）仅适合短文本或浏览器直接点开播放的场景。两个接口功能完全一致、返回格式完全相同。

POST /tts/synthesize ⭐ 推荐

文本转语音（JSON Body 传参），返回音频流（MP3 或 WAV）。不受 URL 长度限制，适合长文本。

前端请求示例

// UniApp H5 - TTS（JSON Body，推荐）
async function tts(text, voice) {
  const res = await fetch('http://192.168.1.197:8090/tts/synthesize', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json; charset=utf-8' },
    body: JSON.stringify({
      text: text,                  // 长文本无压力
      voice: voice || 'zh-CN-XiaoxiaoNeural',
      rate: '+0%',
      fallback: false
    })
  });
  if (!res.ok) throw new Error('TTS 失败: ' + res.status);
  const blob = await res.blob();
  const engine = res.headers.get('X-TTS-Engine');
  return {
    url: URL.createObjectURL(blob),
    engine: engine,              // edge-tts / sherpa-onnx
    format: engine === 'edge-tts' ? 'mp3' : 'wav'
  };
}

POST /tts （Query String，短文本/浏览器直连）

文本转语音，参数通过 Query String 传递，返回音频流（MP3 或 WAV）。适合短文本或直接拼 URL 用 <audio> 播放。

请求参数（Query String）

参数类型必填默认值说明
textstring是—要合成的文本，最大 5000 字
voicestring否zh-CN-XiaoxiaoNeural发音人，见下方声音列表
ratestring否+0%语速，如 +10%（加快）、-5%（减慢）
pitchstring否+0Hz音调，如 +2Hz（升高）、-1Hz（降低）
volumestring否+0%音量，如 +20%（增大）、-10%（减小）
fallbackboolean否falsetrue = 跳过 edge-tts，直接用离线引擎
注意：参数通过 Query String 传递（不是 Body），因为文本可能含特殊字符，前端需用 encodeURIComponent 编码。

Body二进制音频流
X-TTS-Engine响应头：edge-tts 或 sherpa-onnx
X-TTS-Voice响应头：使用的发音人（仅 edge-tts）

前端请求示例

// UniApp H5 - TTS 合成并播放
const text = '你好，欢迎使用语音服务';
const url = `http://192.168.1.197:8090/tts?text=${encodeURIComponent(text)}&voice=zh-CN-XiaoxiaoNeural`;

// 方式1：直接用 audio 标签播放
const audio = document.getElementById('myAudio');
audio.src = url;
audio.play();

// 方式2：fetch 获取 Blob 后播放
const res = await fetch(url);
const blob = await res.blob();
const audioUrl = URL.createObjectURL(blob);
const engine = res.headers.get('X-TTS-Engine'); // "edge-tts" 或 "sherpa-onnx"
console.log('TTS 引擎:', engine);

audio.src = audioUrl;
audio.play();

ASR 语音识别 （Automatic Speech Recognition）

语音转文字。使用 Sherpa-ONNX Streaming Zipformer 中英双语模型（离线本地推理）。

WS /asr/stream

实时流式语音识别（WebSocket）。边说边识别，返回中间结果和最终结果。

通信协议

方向消息格式说明
客户端 → 服务端二进制 (Binary)16-bit PCM 音频帧，16kHz，mono，小端
客户端 → 服务端JSON Text{"action": "stop"} 结束会话
服务端 → 客户端JSON Text识别结果（见下方）

服务端返回消息

// 中间结果（实时显示）
{"text": "你好", "is_final": false, "reason": "partial"}

// 最终结果（句尾静音检测到端点）
{"text": "你好欢迎使用", "is_final": true, "reason": "endpoint"}

// 用户主动停止
{"text": "最终文本", "is_final": true, "reason": "user_stop"}
音频格式要求：WebSocket 推送的音频必须是 16-bit signed PCM, 16kHz, mono, little-endian。这不是 WAV 文件（没有文件头），是裸 PCM 数据。前端需要用 AudioWorklet 或 Web Audio API 采集原始 PCM 帧。

UniApp H5 对接示例

1. 封装 API 模块

// utils/voiceApi.js
const BASE_URL = 'http://192.168.1.197:8090';

// TTS：文本转语音（JSON Body，长文本推荐），返回音频 URL
export async function tts(text, voice, rate, pitch, volume) {
  const res = await fetch(`${BASE_URL}/tts/synthesize`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json; charset=utf-8' },
    body: JSON.stringify({
      text: text,
      voice: voice || 'zh-CN-XiaoxiaoNeural',
      rate: rate || '+0%',
      pitch: pitch,
      volume: volume,
      fallback: false
    })
  });
  if (!res.ok) throw new Error('TTS 失败: ' + res.status);

  const blob = await res.blob();
  const engine = res.headers.get('X-TTS-Engine');
  return {
    url: URL.createObjectURL(blob),
    engine: engine,
    // edge-tts 返回 mp3，sherpa-onnx 返回 wav
    format: engine === 'edge-tts' ? 'mp3' : 'wav'
  };
}

// ASR：音频文件转文字
export async function asrRecognize(audioFilePath) {
  return new Promise((resolve, reject) => {
    uni.uploadFile({
      url: `${BASE_URL}/asr`,
      filePath: audioFilePath,
      name: 'audio',
      success: (res) => {
        const data = JSON.parse(res.data);
        resolve(data);
      },
      fail: reject
    });
  });
}

// ASR 流式识别（WebSocket）
export function asrStream(onResult, onClose) {
  const ws = new WebSocket('ws://192.168.1.197:8090/asr/stream');
  ws.onmessage = (e) => {
    const data = JSON.parse(e.data);
    onResult(data);
  };
  ws.onclose = onClose;
  return ws;
}

// KWS 流式唤醒词检测（WebSocket）
export function kwsStream(onResult, onClose) {
  const ws = new WebSocket('ws://192.168.1.197:8090/kws/stream');
  ws.onmessage = (e) => {
    const data = JSON.parse(e.data);
    if (data.detected) {
      onResult(data);
    }
  };
  ws.onclose = onClose;
  return ws;
}

2. 页面中使用 TTS

<template>
  <view>
    <input v-model="text" placeholder="输入要朗读的文字" />
    <button @click="speak">语音播放</button>
    <audio ref="audio" ></audio>
  </view>
</template>

<script>
import { tts } from '@/utils/voiceApi.js';

export default {
  data() {
    return { text: '你好世界' };
  },
  methods: {
    async speak() {
      try {
        const { url, engine } = await tts(this.text, 'zh-CN-XiaoxiaoNeural');
        this.$refs.audio.src = url;
        await this.$refs.audio.play();
        console.log('播放完成，引擎:', engine);
      } catch (e) {
        uni.showToast({ title: '语音合成失败', icon: 'none' });
      }
    }
  }
}
</script>

3. 录音 + ASR 识别

<template>
  <view>
    <button @touchstart="startRecord" @touchend="stopRecord">按住说话</button>
    <text>{{ result }}</text>
  </view>
</template>

<script>
import { asrRecognize } from '@/utils/voiceApi.js';

const recorder = uni.getRecorderManager();

export default {
  data() {
    return { result: '' };
  },
  onLoad() {
    recorder.onStop(async (res) => {
      try {
        // res.tempFilePath 是录音文件路径
        const data = await asrRecognize(res.tempFilePath);
        this.result = data.text;
      } catch (e) {
        uni.showToast({ title: '识别失败', icon: 'none' });
      }
    });
  },
  methods: {
    startRecord() {
      recorder.start({
        format: 'wav',      // 必须用 wav 或 mp3，不能用 aac
        sampleRate: 16000,
        numberOfChannels: 1,
      });
    },
    stopRecord() {
      recorder.stop();
    }
  }
}
</script>
录音格式关键：uni.getRecorderManager().start({ format: 'wav' }) 必须指定 format: 'wav'，默认可能是 aac，POST /asr 不支持 aac。

代码检查发现的问题

1. ASR POST /asr 不支持 AAC 格式
当前用 librosa.load() 读取文件，librosa 依赖 sndfile 库，sndfile 支持 WAV/MP3/FLAC/OGG，但不支持 AAC。 如果前端强制需要 AAC 上传，后端需加 ffmpeg 转码环节（需安装 ffmpeg）。 建议方案：前端录音时指定 format: 'wav' 或 format: 'mp3'，不传 AAC。
2. ✅ TTS 长文本已支持 Body 传参
已新增 POST /tts/synthesize（JSON Body），参数走请求体不受 URL 长度限制，支持到 5000 字。
原 POST /tts（Query String）保留，适合短文本或浏览器直接拼 URL 播放；长文本请用 Body 接口。
3. WebSocket 音频格式不是文件格式
/asr/stream 和 /kws/stream 要求客户端推送裸 PCM 数据（16-bit, 16kHz, mono, 小端）。 这不能直接用录音文件上传。H5 端需要用 getUserMedia + AudioWorklet 采集 PCM 帧。 UniApp 的 RecorderManager 产出的是文件格式（WAV/MP3），不能直接用于 WebSocket 流。 建议方案：实时流式用原生 H5 API；批量识别用 POST /asr 文件上传。
4. KWS POST /kws/check 仅支持 WAV
和 ASR 不同，KWS 的文件上传接口只支持 WAV（代码用 librosa.load 但后缀依赖文件名扩展名判断）。 MP3 也能被 librosa 读取，但建议统一用 WAV。
5. 无鉴权
当前服务未开启任何鉴权，CORS allow_origins: ["*"]。 调试阶段无问题，生产环境需加 API Key 或走网关鉴权。
